# NUEF

An interactive landing page for a music and creative brand, built with JavaScript, SCSS and GSAP.

**Live demo:** https://nuef.oleksiireznichenko.com

I worked on the frontend, implementing scroll-driven animations, interactive visual elements and responsive layouts. One of the more challenging parts of this project was coordinating multiple GSAP timelines, pinned sections and transitions to create a continuous scrolling experience.

I've recently restored the project as a standalone frontend demo, improved animation pacing and responsiveness, fixed navigation and scrolling issues, and removed the obsolete PHP backend functionality.

## Tech stack

- HTML5
- JavaScript
- SCSS
- GSAP and ScrollTrigger
- SmoothScroll

## Features

- Interactive landing page with scroll-driven animations
- Animated spotlights, typography and visual effects
- Pinned sections with coordinated GSAP timelines
- Rotating vinyl records and interactive disc elements
- Animated phone and studio sections
- Smooth desktop scrolling and section navigation
- Responsive layouts for desktop and mobile devices

## Running locally

You'll need Node.js and npm installed.

```bash
git clone https://github.com/OleksiiReznichenko/NUEF.git
cd NUEF
npm run dev
```

Open http://localhost:5173 in your browser.

The project includes compiled CSS, so dependencies are not required for a basic preview.

To install dependencies and compile SCSS:

```bash
npm install
npm run build:css
```

To run the included project checks:

```bash
npm run check
```
